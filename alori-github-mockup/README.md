# Alori — Website Concept

A free, static, mobile-friendly mock website for the Alori fantasy podcast universe.

## Live demo with GitHub Pages

1. Create a **public** GitHub repository, such as `alori-website-demo`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After GitHub Pages deploys, your URL should look like `https://YOUR-USERNAME.github.io/alori-website-demo/`.

To test locally, double-click `index.html` in a browser.

## Included sections

Home, character cards and detail previews, interactive three-question destiny quiz, world lore, podcasts/campaigns, community (fan art, music, Discord), news, shop placeholder, profile preview, admin dashboard preview, and login/register placeholder.

## Important limitations

- All character names, campaign titles, and lore are illustrative placeholders.
- No accounts, database, user uploads, moderation, or payments exist in this version.
- The quiz result is held in browser memory for the current tab only.
- The login form does not send or save credentials.
- Replace placeholder content and add real social/store links after getting approval from the creators.

## Later upgrade

The concept can be rebuilt with Next.js + Vercel + Supabase for real accounts, persistent quiz results, admin roles, and moderated community submissions.
